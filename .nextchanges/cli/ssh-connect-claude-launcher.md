* `databricks ssh connect` interactive sessions now install a `claude` launcher on the remote PATH. It delegates to the new hidden `databricks ssh agent-shim claude` subcommand, which first checks that the workspace's Unity AI Gateway is enabled (erroring out early with an actionable message if it isn't), then installs ucode + Claude Code (and Node/npm) on first run and launches a ucode-configured Claude Code. Subsequent runs skip straight to launching it, so any session gets a ucode-configured Claude Code with no extra flags.
